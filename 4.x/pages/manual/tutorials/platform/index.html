Godot 4.7

Platform-specific

Godot supports both running the editor and exporting projects on several platforms. Usage of the engine is generally similar across platforms, but there are some platform-specific considerations, which are covered in this section.

See also: For platform-specific versions of the editor, see doc_using_the_xr_editor, doc_using_the_android_editor, and doc_using_the_web_editor. For exporting to specific platforms, see the doc_export_index section.
