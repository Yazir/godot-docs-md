MeshLibrary

Inherits: Resource < RefCounted < Object

Library of meshes.

Description

A library of meshes. Contains a list of Mesh resources, each with a name and ID. Each item can also include collision and navigation shapes. This resource is used in GridMap.

Properties

String item/{index}/category = &""

The item's category. Used to organize meshes in the GridMap editor. A category can include / as a delimiter to create subcategories.

Mesh item/{index}/mesh

The item's mesh. Used by other parts of the engine (e.g. GridMap, which displays them in a 3D tile).

int item/{index}/mesh_cast_shadow = 1

The shadow casting mode used by the item's mesh. See RenderingServer.ShadowCastingSetting.

Transform3D item/{index}/mesh_transform = Transform3D(1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)

The transform to apply to the item's mesh.

String item/{index}/name = ""

The item's name, shown in the editor. It can also be used to look up the item later using find_item_by_name().

int item/{index}/navigation_layers = 1

The item's navigation layers bitmask.

NavigationMesh item/{index}/navigation_mesh

The item's navigation mesh.

Transform3D item/{index}/navigation_mesh_transform = Transform3D(1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)

The transform to apply to the item's navigation mesh.

Texture2D item/{index}/preview

The texture to use as the item's preview icon in the editor.

Array item/{index}/shapes = []

The item's collision shapes. The array should consist of Shape3D objects, each followed by a Transform3D that will be applied to it. For shapes that should not have a transform, use Transform3D.IDENTITY.

When running in the editor, returns a generated item preview (a 3D rendering in isometric perspective). When used in a running project, returns the manually-defined item preview which can be set using set_item_preview(). Returns an empty Texture2D if no preview was manually set in a running project.
