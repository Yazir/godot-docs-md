FuzzySearchMatch

Result returned by FuzzySearch containing match information.

Properties

int original_index = -1

  • Setter: set_original_index(value: int)
  • Getter: get_original_index()

The original index of target in the provided array of targets when using FuzzySearch.search_all() otherwise -1.

int score = 0

  • Setter: set_score(value: int)
  • Getter: get_score()

Match score determined by FuzzySearch. Scores are not normalized and generally should not be directly compared between different queries.

String target = ""

  • Setter: set_target(value: String)
  • Getter: get_target()

Target string which was matched against.

Methods

Array\[Vector2i\] get_matched_substrings() const

Returns each matched substring interval of target. The Vector2i.x component is the start of the interval and the Vector2i.y component is the length, corresponding to the arguments for String.substr().
