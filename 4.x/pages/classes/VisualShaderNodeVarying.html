VisualShaderNodeVarying

Inherits: VisualShaderNode < Resource < RefCounted < Object

Implemented by: VisualShaderNodeVaryingGetter, VisualShaderNodeVaryingSetter

A visual shader node that represents a "varying" shader value.

Description

Varying values are shader variables that can be passed between shader functions, e.g. from Vertex shader to Fragment shader.

Properties

String varying_name = "[None]"

  • Setter: set_varying_name(value: String)
  • Getter: get_varying_name()

Name of the variable. Must be unique.

``VisualShader.VaryingType varying_type = 0

  • Setter: set_varying_type(value: VisualShader.VaryingType)
  • Getter: get_varying_type()

Type of the variable. Determines where the variable can be accessed.
