RenderSceneBuffersConfiguration

Inherits: RefCounted < Object

Configuration object used to setup a RenderSceneBuffers object.

Description

This configuration object is created and populated by the render engine on a viewport change and used to (re)configure a RenderSceneBuffers object.

Properties

``RenderingServer.ViewportAnisotropicFiltering anisotropic_filtering_level = 2

  • Setter: set_anisotropic_filtering_level(value: RenderingServer.ViewportAnisotropicFiltering)
  • Getter: get_anisotropic_filtering_level()

Level of the anisotropic filter.

float fsr_sharpness = 0.0

  • Setter: set_fsr_sharpness(value: float)
  • Getter: get_fsr_sharpness()

FSR Sharpness applicable if FSR upscaling is used.

Vector2i internal_size = Vector2i(0, 0)

  • Setter: set_internal_size(value: Vector2i)
  • Getter: get_internal_size()

The size of the 3D render buffer used for rendering.

  • Getter: get_msaa_3d()

The render target associated with these buffer.

  • Setter: set_screen_space_aa(value: RenderingServer.ViewportScreenSpaceAA)
