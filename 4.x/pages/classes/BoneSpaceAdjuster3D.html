BoneSpaceAdjuster3D

Inherits: SkeletonModifier3D < Node3D < Node < Object

Inputs a scale and converts it to the position of a child bone.

Description

Inputs a scale and converts it to the position of a child bone. Intended for use in combination with Skeleton3D.set_bone_skin_scale().

This modifier repositions child bones to follow the skin transformation by Skeleton3D.set_bone_skin_scale() in cases when you want to adjust bone length using Skeleton3D.set_bone_skin_scale() or when the bone has multiple child bones.

Properties

int setting_size

  • Setter: set_setting_size(value: int)
  • Getter: get_setting_size()

The number of settings in the modifier.

bool use_bone_skin_scale_for_all_bones = true

  • Setter: set_use_bone_skin_scale_for_all_bones(value: bool)
  • Getter: are_all_bones_using_bone_skin_scale()

If true, this modifier processes all bones for which Skeleton3D.get_bone_skin_scale() is not Vector3(1, 1, 1).

If false, this modifier allows you to configure whether to process bone skin scaling individually in the settings.
