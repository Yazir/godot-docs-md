StatusIndicator

Inherits: Node < Object

Application status indicator (aka notification area icon).

Note: Status indicator is implemented on macOS and Windows.

Properties

Texture2D icon

  • Setter: set_icon(value: Texture2D)
  • Getter: get_icon()

Status indicator icon.

NodePath menu = NodePath("")

  • Setter: set_menu(value: NodePath)
  • Getter: get_menu()

Status indicator native popup menu. If this is set, the pressed signal is not emitted.

Note: Native popup is only supported if NativeMenu supports NativeMenu.FEATURE_POPUP_MENU feature.

String tooltip = ""

  • Setter: set_tooltip(value: String)
  • Getter: get_tooltip()

Status indicator tooltip.

bool visible = true

  • Setter: set_visible(value: bool)
  • Getter: is_visible()

If true, the status indicator is visible.

Methods

Rect2 get_rect() const

Returns the status indicator rectangle in screen coordinates. If this status indicator is not visible, returns an empty Rect2.

Signals

pressed(mouse_button: int, mouse_position: Vector2i)

Emitted when the status indicator is pressed.
