InputEventFromWindow

Inherits: InputEvent < Resource < RefCounted < Object

Implemented by: InputEventScreenDrag, InputEventScreenTouch, InputEventWithModifiers

Abstract base class for Viewport-based input events.

Description

InputEventFromWindow represents events specifically received by windows. This includes mouse events, keyboard events in focused windows or touch screen actions.

Properties

int window_id = 0

  • Setter: set_window_id(value: int)
  • Getter: get_window_id()

The ID of a Window that received this event.
