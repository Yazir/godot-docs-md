AudioStreamPlayer2D

Inherits: Node2D < CanvasItem < Node < Object

Plays positional sound in 2D space.

Description

Plays audio that dampens with distance from a given position.

By default, audio is heard from the screen center. This can be changed by adding a Listener2D node to the scene and enabling it by calling Listener2D.make_current on it.

See also AudioStreamPlayer to play a sound non-positionally.

Note: Hiding an AudioStreamPlayer2D node does not disable its audio output. To temporarily disable an AudioStreamPlayer2D's audio output, set volume_db to a very low value like -100 (which isn't audible to human hearing).

Properties

int area_mask = 1

  • Setter: set_area_mask(value: int)
  • Getter: get_area_mask()

Determines which Area2D layers affect the sound for reverb and audio bus effects. Areas can be used to redirect AudioStream s so that they play in a certain audio bus. An example of how you might use this is making a "water" area so that sounds played in the water are redirected through an audio bus to make them sound like they are being played underwater.

float attenuation = 1.0

  • Setter: set_attenuation(value: float)
  • Getter: get_attenuation()

Dampens audio over distance with this as an exponent.

bool autoplay = false

  • Setter: set_autoplay(value: bool)
  • Getter: is_autoplay_enabled()

If true, audio plays when added to scene tree.

String bus = "Master"

  • Setter: set_bus(value: String)
  • Getter: get_bus()

Bus on which this audio is playing.

Note: When setting this property, keep in mind that no validation is performed to see if the given name matches an existing bus. This is because audio bus layouts might be loaded after this property is set. If this given name can't be resolved at runtime, it will fall back to "Master".

float max_distance = 2000.0

  • Setter: set_max_distance(value: float)
  • Getter: get_max_distance()

Maximum distance from which audio is still hearable.

float panning_strength = 1.0

  • Setter: set_panning_strength(value: float)
  • Getter: get_panning_strength()

Scales the panning strength for this node by multiplying the base ProjectSettings.audio/2d_panning_strength with this factor. Higher values will pan audio from left to right more dramatically than lower values.

float pitch_scale = 1.0

  • Setter: set_pitch_scale(value: float)
  • Getter: get_pitch_scale()

The pitch and the tempo of the audio, as a multiplier of the audio sample's sample rate.

bool playing = false

  • Getter: is_playing()

If true, audio is playing.

AudioStream stream

  • Setter: set_stream(value: AudioStream)
  • Getter: get_stream()

The AudioStream object to be played.

bool stream_paused = false

  • Setter: set_stream_paused(value: bool)
  • Getter: get_stream_paused()

If true, the playback is paused. You can resume it by setting stream_paused to false.

float volume_db = 0.0

  • Setter: set_volume_db(value: float)
  • Getter: get_volume_db()

Base volume without dampening.

Methods

void stop()
