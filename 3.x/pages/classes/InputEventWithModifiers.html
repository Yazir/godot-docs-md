InputEventWithModifiers

Inherits: InputEvent < Resource < Reference < Object

Implemented by: InputEventGesture, InputEventKey, InputEventMouse

Base class for keys events with modifiers.

Description

Contains keys events information with modifiers support like :kbd:Shift or :kbd:Alt. See Node._input.
