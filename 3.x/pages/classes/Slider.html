Godot 3.6

Slider

Inherits: Range < Control < CanvasItem < Node < Object

Implemented by: HSlider, VSlider

Base class for GUI sliders.

Description

Base class for GUI sliders.

Note: The Range.changed and Range.value_changed signals are part of the Range class which this class inherits from.

Properties

bool editable = true

  • Setter: set_editable(value: bool)
  • Getter: is_editable()

If true, the slider can be interacted with. If false, the value can be changed only by code.

bool scrollable = true

  • Setter: set_scrollable(value: bool)
  • Getter: is_scrollable()

If true, the value can be changed using the mouse wheel.

int tick_count = 0

  • Setter: set_ticks(value: int)
  • Getter: get_ticks()

Number of ticks displayed on the slider, including border ticks. Ticks are uniformly-distributed value markers.

bool ticks_on_borders = false

  • Setter: set_ticks_on_borders(value: bool)
  • Getter: get_ticks_on_borders()

If true, the slider will display ticks for minimum and maximum values.

Signals

drag_ended(value_changed: bool)

Emitted when dragging stops. If value_changed is true, Range.value is different from the value when you started the dragging.

drag_started()

Emitted when dragging is started.
