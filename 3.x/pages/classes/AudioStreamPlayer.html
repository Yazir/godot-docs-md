AudioStreamPlayer

Inherits: Node < Object

Plays back audio non-positionally.

Description

Plays an audio stream non-positionally.

To play audio positionally, use AudioStreamPlayer2D or AudioStreamPlayer3D instead of AudioStreamPlayer.

Properties

bool autoplay = false

  • Setter: set_autoplay(value: bool)
  • Getter: is_autoplay_enabled()

If true, audio plays when added to scene tree.

String bus = "Master"

  • Setter: set_bus(value: String)
  • Getter: get_bus()

Bus on which this audio is playing.

Note: When setting this property, keep in mind that no validation is performed to see if the given name matches an existing bus. This is because audio bus layouts might be loaded after this property is set. If this given name can't be resolved at runtime, it will fall back to "Master".

``MixTarget mix_target = 0

  • Setter: set_mix_target(value: MixTarget)
  • Getter: get_mix_target()

If the audio configuration has more than two speakers, this sets the target channels. See MixTarget constants.

float pitch_scale = 1.0

  • Setter: set_pitch_scale(value: float)
  • Getter: get_pitch_scale()

The pitch and the tempo of the audio, as a multiplier of the audio sample's sample rate.

bool playing = false

  • Getter: is_playing()

If true, audio is playing.

AudioStream stream

  • Setter: set_stream(value: AudioStream)
  • Getter: get_stream()

The AudioStream object to be played.

bool stream_paused = false

  • Setter: set_stream_paused(value: bool)
  • Getter: get_stream_paused()

If true, the playback is paused. You can resume it by setting stream_paused to false.

float volume_db = 0.0

  • Setter: set_volume_db(value: float)
  • Getter: get_volume_db()

Volume of sound, in dB.

Methods

float get_playback_position()

Returns the position in the AudioStream in seconds.

AudioStreamPlayback get_stream_playback()

Returns the AudioStreamPlayback object associated with this AudioStreamPlayer.

void play(from_position=0.0: float)

Plays the audio from the given from_position, in seconds.

void seek(to_position: float)

Sets the position from which audio will be played, in seconds.

void stop()

Stops the audio.

Signals

finished()

Emitted when the audio stops playing.

Enumerations

enum MixTarget

  • MIX_TARGET_STEREO = 0

    The audio will be played only on the first channel.

  • MIX_TARGET_SURROUND = 1

    The audio will be played on all surround channels.

  • MIX_TARGET_CENTER = 2

    The audio will be played on the second channel, which is usually the center.
