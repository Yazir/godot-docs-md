InputEventMouseButton

Inherits: InputEventMouse < InputEventWithModifiers < InputEvent < Resource < Reference < Object

Input event type for mouse button events.

Description

Contains mouse click information. See Node._input.

Note: On Wear OS devices, rotary input is mapped to @GlobalScope.BUTTON_WHEEL_UP and @GlobalScope.BUTTON_WHEEL_DOWN. This can be changed to @GlobalScope.BUTTON_WHEEL_LEFT and @GlobalScope.BUTTON_WHEEL_RIGHT with the ProjectSettings.input_devices/pointing/android/rotary_input_scroll_axis setting.

Properties

int button_index = 0

  • Setter: set_button_index(value: int)
  • Getter: get_button_index()

The mouse button identifier, one of the @GlobalScope.ButtonList button or button wheel constants.

bool canceled = false

  • Setter: set_canceled(value: bool)
  • Getter: is_canceled()

If true, the mouse button event has been canceled.

bool doubleclick = false

  • Setter: set_doubleclick(value: bool)
  • Getter: is_doubleclick()

If true, the mouse button's state is a double-click.

float factor = 1.0

  • Setter: set_factor(value: float)
  • Getter: get_factor()

The amount (or delta) of the event. When used for high-precision scroll events, this indicates the scroll amount (vertical or horizontal). This is only supported on some platforms; the reported sensitivity varies depending on the platform. May be 0 if not supported.

bool pressed = false

  • Setter: set_pressed(value: bool)
  • Getter: is_pressed()

If true, the mouse button's state is pressed. If false, the mouse button's state is released.
