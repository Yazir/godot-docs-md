InputEventScreenTouch

Inherits: InputEvent < Resource < Reference < Object

Input event type for screen touch events.

(only available on mobile devices)

Description

Stores multi-touch press/release information. Supports touch press, touch release and index for multi-touch count and order.

Tutorials

  • :doc:../tutorials/inputs/inputevent

Properties

bool canceled = false

  • Setter: set_canceled(value: bool)
  • Getter: is_canceled()

If true, the touch event has been canceled.

bool double_tap = false

  • Setter: set_double_tap(value: bool)
  • Getter: is_double_tap()

If true, the touch's state is a double tap.

int index = 0

  • Setter: set_index(value: int)
  • Getter: get_index()

The touch index in the case of a multi-touch event. One index = one finger.

Vector2 position = Vector2( 0, 0 )

  • Setter: set_position(value: Vector2)
  • Getter: get_position()

The touch position.

bool pressed = false

  • Setter: set_pressed(value: bool)
  • Getter: is_pressed()

If true, the touch's state is pressed. If false, the touch's state is released.
