LightOccluder2D

Inherits: Node2D < CanvasItem < Node < Object

Occludes light cast by a Light2D, casting shadows.

Description

Occludes light cast by a Light2D, casting shadows. The LightOccluder2D must be provided with an OccluderPolygon2D in order for the shadow to be computed.

Tutorials

  • :doc:../tutorials/2d/2d_lights_and_shadows

Properties

int light_mask = 1

  • Setter: set_occluder_light_mask(value: int)
  • Getter: get_occluder_light_mask()

The LightOccluder2D's light mask. The LightOccluder2D will cast shadows only from Light2D(s) that have the same light mask(s).

OccluderPolygon2D occluder

  • Setter: set_occluder_polygon(value: OccluderPolygon2D)
  • Getter: get_occluder_polygon()

The OccluderPolygon2D used to compute the shadow.
