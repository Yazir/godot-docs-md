Container

Inherits: Control < CanvasItem < Node < Object

Implemented by: AspectRatioContainer, BoxContainer, CenterContainer, EditorProperty, FlowContainer, GraphNode, GridContainer, MarginContainer, PanelContainer, ScrollContainer, SplitContainer, TabContainer, ViewportContainer

Base node for containers.

Description

Base node for containers. A Container contains other controls and automatically arranges them in a certain way.

A Control can inherit this to create custom container classes.

Methods

void fit_child_in_rect(child: Control, rect: Rect2)

Fit a child control in a given rect. This is mainly a helper for creating custom container classes.

void queue_sort()

Queue resort of the contained children. This is called automatically anyway, but can be called upon request.

Signals

sort_children()

Emitted when sorting the children is needed.

Constants

Notification for when sorting the children, it must be obeyed immediately.
