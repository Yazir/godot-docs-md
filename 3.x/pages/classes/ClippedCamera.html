ClippedCamera

Inherits: Camera < Spatial < Node < Object

A Camera that includes collision.

Description

This node extends Camera to add collisions with Area and/or PhysicsBody nodes. The camera cannot move through colliding objects.

Properties

bool clip_to_areas = false

  • Setter: set_clip_to_areas(value: bool)
  • Getter: is_clip_to_areas_enabled()

If true, the camera stops on contact with Area s.

bool clip_to_bodies = true

  • Setter: set_clip_to_bodies(value: bool)
  • Getter: is_clip_to_bodies_enabled()

If true, the camera stops on contact with PhysicsBody s.

int collision_mask = 1

  • Setter: set_collision_mask(value: int)
  • Getter: get_collision_mask()

The camera's collision mask. Only objects in at least one collision layer matching the mask will be detected. See Collision layers and masks <../tutorials/physics/physics_introduction.html#collision-layers-and-masks>__ in the documentation for more information.

float margin = 0.0

  • Setter: set_margin(value: float)
  • Getter: get_margin()

The camera's collision margin. The camera can't get closer than this distance to a colliding object.

``ProcessMode process_mode = 0

  • Setter: set_process_mode(value: ProcessMode)
  • Getter: get_process_mode()

The camera's process callback. See ProcessMode.

Methods

void add_exception(node: Object)

Adds a collision exception so the camera does not collide with the specified node.

void add_exception_rid(rid: RID)

Adds a collision exception so the camera does not collide with the specified RID.

void clear_exceptions()

Removes all collision exceptions.

float get_clip_offset() const

Returns the distance the camera has been offset due to a collision.

bool get_collision_mask_bit(bit: int) const

Returns true if the specified bit index is on.

Note: Bit indices range from 0-19.

void remove_exception(node: Object)

Removes a collision exception with the specified node.

void remove_exception_rid(rid: RID)

Removes a collision exception with the specified RID.

void set_collision_mask_bit(bit: int, value: bool)

Sets the specified bit index to the value.

Note: Bit indices range from 0-19.

Enumerations
