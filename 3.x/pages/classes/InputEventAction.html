InputEventAction

Inherits: InputEvent < Resource < Reference < Object

Input event type for actions.

Description

Contains a generic action which can be targeted from several types of inputs. Actions can be created from the Input Map tab in the Project > Project Settings menu. See Node._input.

Properties

String action = ""

  • Setter: set_action(value: String)
  • Getter: get_action()

The action's name. Actions are accessed via this String.

bool pressed = false

  • Setter: set_pressed(value: bool)
  • Getter: is_pressed()

If true, the action's state is pressed. If false, the action's state is released.

float strength = 1.0

  • Setter: set_strength(value: float)
  • Getter: get_strength()

The action's strength between 0 and 1. This value is considered as equal to 0 if pressed is false. The event strength allows faking analog joypad motion events, by specifying how strongly the joypad axis is bent or pressed.
