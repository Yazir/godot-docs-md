PhysicsShapeQueryParameters

Inherits: Reference < Object

Parameters to be sent to a 3D shape physics query.

Description

This class contains the shape and other parameters for 3D intersection/collision queries.

Properties

bool collide_with_areas = false

  • Setter: set_collide_with_areas(value: bool)
  • Getter: is_collide_with_areas_enabled()

If true, the query will take Area s into account.

bool collide_with_bodies = true

  • Setter: set_collide_with_bodies(value: bool)
  • Getter: is_collide_with_bodies_enabled()

If true, the query will take PhysicsBody s into account.

int collision_mask = 2147483647

  • Setter: set_collision_mask(value: int)
  • Getter: get_collision_mask()

The physics layer(s) the query will take into account (as a bitmask). See Collision layers and masks <../tutorials/physics/physics_introduction.html#collision-layers-and-masks>__ in the documentation for more information.

Array exclude = [ ]

  • Setter: set_exclude(value: Array)
  • Getter: get_exclude()

The list of objects or object RID s that will be excluded from collisions.

float margin = 0.0

  • Setter: set_margin(value: float)
  • Getter: get_margin()

The collision margin for the shape.

RID shape_rid

  • Setter: set_shape_rid(value: RID)
  • Getter: get_shape_rid()

The queried shape's RID. See also set_shape.

Transform transform = Transform( 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0 )

  • Setter: set_transform(value: Transform)
  • Getter: get_transform()

The queried shape's transform matrix.

Methods

void set_shape(shape: Resource)

Sets the Shape that will be used for collision/intersection queries.
