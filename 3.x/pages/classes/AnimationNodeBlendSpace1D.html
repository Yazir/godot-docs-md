AnimationNodeBlendSpace1D

Inherits: AnimationRootNode < AnimationNode < Resource < Reference < Object

Blends linearly between two of any number of AnimationNode of any type placed on a virtual axis.

Description

A resource to add to an AnimationNodeBlendTree.

This is a virtual axis on which you can add any type of AnimationNode using add_blend_point.

Outputs the linear blend of the two AnimationNode s closest to the node's current value.

You can set the extents of the axis using the min_space and max_space.

Properties

float max_space = 1.0

  • Setter: set_max_space(value: float)
  • Getter: get_max_space()

The blend space's axis's upper limit for the points' position. See add_blend_point.

float min_space = -1.0

  • Setter: set_min_space(value: float)
  • Getter: get_min_space()

The blend space's axis's lower limit for the points' position. See add_blend_point.

float snap = 0.1

  • Setter: set_snap(value: float)
  • Getter: get_snap()

Position increment to snap to when moving a point on the axis.

String value_label = "value"

  • Setter: set_value_label(value: String)
  • Getter: get_value_label()

Label of the virtual axis of the blend space.

Methods

void add_blend_point(node: AnimationRootNode, pos: float, at_index=-1: int)

Adds a new point that represents a node on the virtual axis at a given position set by pos. You can insert it at a specific index using the at_index argument. If you use the default value for at_index, the point is inserted at the end of the blend points array.

int get_blend_point_count() const

Returns the number of points on the blend axis.

AnimationRootNode get_blend_point_node(point: int) const

Returns the AnimationNode referenced by the point at index point.

float get_blend_point_position(point: int) const

Returns the position of the point at index point.

void remove_blend_point(point: int)

Removes the point at index point from the blend axis.

void set_blend_point_node(point: int, node: AnimationRootNode)

Changes the AnimationNode referenced by the point at index point.

void set_blend_point_position(point: int, pos: float)

Updates the position of the point at index point on the blend axis.
