InputEventJoypadButton

Inherits: InputEvent < Resource < Reference < Object

Input event for gamepad buttons.

Description

Input event type for gamepad buttons. For gamepad analog sticks and joysticks, see InputEventJoypadMotion.

Tutorials

  • :doc:../tutorials/inputs/inputevent

Properties

int button_index = 0

  • Setter: set_button_index(value: int)
  • Getter: get_button_index()

Button identifier. One of the @GlobalScope.JoystickList button constants.

bool pressed = false

  • Setter: set_pressed(value: bool)
  • Getter: is_pressed()

If true, the button's state is pressed. If false, the button's state is released.

float pressure = 0.0

  • Setter: set_pressure(value: float)
  • Getter: get_pressure()

Represents the pressure the user puts on the button with their finger, if the controller supports it. Ranges from 0 to 1.

Note: This property is never set by the engine and is always 0.
