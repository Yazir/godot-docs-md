Godot 3.6

Quick start guide

  • Turn on physics interpolation: ref
  • Make sure you move objects and run your game logic in _physics_process() rather than _process(). This includes moving objects directly and indirectly (by e.g. moving a parent, or using another mechanism to automatically move nodes).
  • Be sure to call ref on nodes after you first position or teleport them, to prevent "streaking"
  • Temporarily try setting ref to 10 to see the difference with and without interpolation.
