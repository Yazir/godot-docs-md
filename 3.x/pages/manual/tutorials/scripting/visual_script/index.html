Godot 3.6

VisualScript

Warning: Godot 4.0 will remove VisualScript from core entirely. As a result, creating new projects using visual scripting in Godot is not recommended. Future Godot 4.x releases may have VisualScript reimplemented as an extension.

While Godot 3.x will keep VisualScript supported, we recommend ref instead, especially if you intend to migrate your project to Godot 4.
